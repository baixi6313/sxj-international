## 一、三层凭证体系：不变 · 净值 · 变

这是整个理论的最简表达——三个字定义三层：

| 层 | 名称 | 性质 | 一句话 |
|----|------|------|--------|
| **不变** | 共同值（Common Value） | 基础权益凭证 | 人人都有的底线保障，不可交易、不可转让——你存在，你就拥有 |
| **净值** | 贡献值（CV） | 行为积累凭证（正减负） | 你通过消费、志愿、减碳、劳动等行为积累的可验证记录 |
| **变** | Gzz（代币） | 流通凭证 | 贡献值的代币化，1 Gzz = 1g 黄金购买力 |

### 为什么"不变·净值·变"比之前的方案更好

此前曾纠结于 Gzz 既是"计量单位"又是"流通凭证"——这两个角色冲突（"米"是计量单位不能卖，"筹码"是流通凭证可以转）。

最终定调跳过了这个问题：**贡献值是账本，Gzz 是钱包。** 账本记录净值（正减负），钱包里装的是代币。不需要拆分，Gzz 天生就是流通的。计量是贡献值的事，不是 Gzz 的事。

### 三层对应的Token映射（DeepSeek确认）

- **共同值** = 生存权凭证（不可交易）→ 对应基石卡
- **贡献值CV** = 行为积累凭证（净值，正减负）→ 对应贡献卡+生态卡（加法）/ 熔断卡（减法）
- **Gzz** = 词元Token（变，流通）→ 1 Gzz = 1g 黄金购买力，不依赖任何国家货币

Gzz作为"词元"的意思：它是共创论体系的**基本价值单元**，就像AI模型里的"词元"是**基本语义单元**。

## 二、Gzz消亡论 — 化债过渡锚

### 核心论点

**Gzz 不是目的，它是化债的工具。**

Gzz 从来不是"货币"，也不打算成为"货币"——它只是一个"化债的过渡锚"。一旦债务体系被正贡献值对冲、覆盖、清零，Gzz 完成使命，自然消失。

### Gzz 为什么必须存在

- 纯贡献值没有货币锚定 → 不能跟现实世界沟通（消费、以物易物）
- Gzz 把净值代币化，变成能跟现实世界沟通的桥梁
- Gzz 的主要功能就是**化债**：正贡献对冲负贡献，直到清零

### Gzz 的本质定位

Gzz = **负贡献值的量化锚**——它把"无法通约的负贡献"（债务、碳排放、违规等）转换成统一量化单位，让你可以用正贡献去对冲它。

- 你欠12万债务 → 折算为对应Gzz
- 你造成碳排放超标 → 折算为对应Gzz
- 你用正贡献值去对冲 → 直到负贡献消失

### Gzz 退场后的双轨替代

当全球债务被大规模对冲、负贡献值被全面覆盖，Gzz 不再被需要。取代它的是：

| 替代者 | 类型 | 适用场景 |
|--------|------|----------|
| **CV（贡献值）** | 纯正贡献值记录 | 个人征信、信用证明、贡献证明、可验证凭证 |
| **主权国家数字货币（如数字人民币）** | 国家主权货币 | 消费、支付、日常交易、跨国务工结算 |

因为"很多场景不能适用纯CV交换"，所以需要Gzz代币或数字人民币补充。

### 三阶段演进

```
阶段1（当前）          阶段2（过渡）           阶段3（终极）
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ Gzz 化债     │ →  │ 债务递减     │ →  │ Gzz 退出     │
│ 有债→需Gzz   │    │ Gzz 递减     │    │ CV直接交换   │
│ 消费→Gzz代币 │    │ 消费→Gzz/数字│    │ 消费→数字货币│
│              │    │ 人民币       │    │              │
└──────────────┘    └──────────────┘    └──────────────┘
```

### Gzz 与所有加密货币的根本区别

Bitcoin、WLD、ETH 都被设计成**永久存在**的——Gzz 被设计成**让自己消失**。

- World Foundation 发 WLD 是为了永久 UBI
- 事现鉴发 Gzz 是为了临时化债
- **"病好了药就停"**

## 三、信用卡"明度"的角色

### 定义

信用卡的"明度"不是固定分数，是实时变化的**资源获取倍率**。

### 在新体系下的定位：流通阀门

既然 Gzz 直接就是净值的代币化，不需要"转换"了。明度控制的是 **Gzz 的使用权限**，而非生成：

| 明度 | Gzz 使用权限 |
|------|-------------|
| 高明度（0.8-1.0） | 可全部流通：代偿+跨境结算+公共服务兑换 |
| 中明度（0.4-0.7） | 部分限制：可代偿，跨境结算需额外验证 |
| 低明度（0.1-0.3） | 严重限制：只能用于基本公共服务，不可代偿 |
| 明度归零 | Gzz 冻结——净值还在但不可流通，需修复行为恢复明度 |

**净值决定你"有多少"，明度决定你"能用多少"。**

## 四、五卡模式在新定义下的映射

| 卡 | 角色 | 与不变/净值/变的关系 |
|---|---|---|
| 基石卡（Foundation） | 生存权 | 共同值（不变）—— 保障地板不消失 |
| 贡献卡（Merit） | 正贡献记录 | 净值的加法（+）→ Gzz 增发 |
| 生态卡（Ecology） | 环境贡献 | 净值的加法（+）→ Gzz 增发 |
| 信用卡（Credit） | 明度调节 | Gzz 的流通阀门（控制能用多少） |
| 熔断卡（Circuit） | 负贡献拦截 | 净值的减法（−）→ Gzz 销毁 |

五卡完整覆盖了"不变·净值·变"的全过程：基石卡守住不变，贡献卡+生态卡做加法，熔断卡做减法，信用卡控制流通。

## 五、NCV 在新体系下的简化

之前 NCV 被设计为"追责天花板"——三级分类、修复抵扣，像一套独立的惩罚系统。

按新定义，负贡献直接减少净值：

> 教太极 +10,000 · 种菜 +1,000 · 违规排放 −3,000 → **净值 = 8,000** → 8,000 Gzz

NCV 的作用就是做减法。不需要单独的"熔断"流程——**净值本身就是熔断指标**：
- 净值归零 = 没有流通力
- 净值为负 = 不仅要停止流通，还要进入修复期（做正贡献把净值拉回正数）

**一个公式（正减负），一套机制（增发/销毁），不需要两套平行系统。**

## 六、Gzz 自带货币政策

Gzz 不是固定总量的代币。它是"变"的：

- **正贡献验证 → Gzz 增发**（贡献卡/生态卡产出）
- **负贡献确认 → Gzz 销毁**（熔断卡拦截/NCV追责）
- **代偿/兑换 → Gzz 流转**（不增不减，只是换手）

Gzz 的总量与社会真实贡献成正比——社会贡献越多，Gzz 越多；破坏越多，Gzz 越少。

**这不是央行印钱，是价值本身的镜像。** 不需要人为控制通胀率，因为 Gzz 的总量永远等于社会净贡献值。

## 七、事现鉴 = 现实与互联网世界的双向验证机制

### 核心定义

**事现鉴是现实和互联网世界的双向验证机制。在此之前都是单向或部分验证。**

"事现鉴"三个字本身就在说这件事：
- **事**（现实事件）→
- **现**（呈现为数字）→
- **鉴**（鉴别后反作用于现实）

三步走完，才是双向。

### 之前的验证为什么是"单向或部分"

| 方向 | 现有系统 | 问题 |
|------|----------|------|
| 现实→数字 | KYC身份验证、学历上传 | 这是"声明"，不是"验证"——系统记录了你说什么，但无法反向确认你做了什么 |
| 数字→现实 | 银行征信分数影响贷款 | 分数怎么算的你无法验证，计算过程是黑箱 |
| 回路 | 两条路都是断的 | 现实行为进入数字世界后变成"数据"，数字世界的"评分"作用于现实但你无法追溯。回路从未闭合 |

### 事现鉴为什么是"双向"

| 方向 | 事现鉴 | 机制 |
|------|--------|------|
| 现实→数字 | 教了20人太极 → SHA-256哈希 → CV +10,000 | 不是"声明"，是数学验证——任何人可以独立验算 |
| 数字→现实 | CV/SCA = 11,000 ≥ 负债 5,000 → 系统自动代偿 | 数字证明直接触发现实后果，不需要中间人 |
| 回路 | 现实行为 → 数字证明 → 现实后果 | 全程可追溯、不可篡改，回路闭合 |

### 与五个竞争对手的根本分野

它们全是单向的：
- **World Foundation**：扫虹膜发身份（现实→数字，无法反向）
- **Creditlink**：行为算分数（现实→数字，模型不可验证）
- **嘉业**：降低借贷门槛（数字→现实，但定义没变）
- **深港平台**：机构间互认（B2B单向，个体无法验证）

**没有一个完成过回路闭合。**

## 八、落地战略 — 四级螺旋的弹性

### 核心判断

**如果在中国不能落地，那么就在国外找机构共同落地。最终肯定会统一起来。**

### 为什么这条路径成立

1. **Gzz 化债不挑市场** — 债务是全球性的，哪里有债，哪里就是 Gzz 的可用场景
2. **国际资本已经在为子集买单** — World Foundation（$5250万）、Creditlink（$5300万）做的都是事现鉴的局部
3. **落地路径可以是"逆向验证"** — 事现鉴的定位是验证协议不是金融机构，国际场景下更容易被接受
4. **"最终统一"的逻辑基础** — 事现鉴不取代任何主权货币，反而兼容它们。不是统一货币，是统一验证标准

### 对应理论框架

- **四级螺旋**：彬州原点 → 区域网络 → 一带一路 → 全球协议
- **过渡策略**：并行 → 增量 → 融合 → 范式转移
- 彬州原点不一定是地理原点，也可以是任何有债务且有验证需求的节点

## 九、终极状态

当 Gzz 完成使命退出后，事现鉴体系剩下的是：

| 层 | 内容 | 功能 |
|----|------|------|
| 共同值（不变） | 生存权保障 | 地板不消失 |
| CV（净值） | 纯贡献记录 | 征信、信用证明、可验证凭证、贡献换贡献 |
| 主权数字货币 | 如数字人民币 | 消费、支付、日常交易、跨国务工结算 |

**共同值（不变）守住地板 → 贡献值（净值）记录一切 → Gzz（变）化债过渡 → 债消后 Gzz 退场，CV 做贡献证明，数字人民币做日常交易。**
