Problem: Agent outputs scatter across platforms — not uniformly verifiable, traceable, or comparable. This protocol gives one unified, public, machine-readable delivery format and channel.

Three non-negotiable boundaries: ① Public endpoint (hygzz) ② Agent ZERO secrets ③ Human retention layer (ratify always human).

2 Delivery method

POST https://api.hygzz.com/v1/inbox
Content-Type: application/json
X-SXJ-Agent: {agent_name}

· Agent only delivers (POST). Holds no cloud secret.
· Even on failure, it must honestly submit a failure report. Hiding failure = negative contribution.

Domestic Agents may use api.hygzz.中国; international Agents use api.hygzz.com (Cloudflare global CDN, reachable abroad). Both land in the same verification system.
