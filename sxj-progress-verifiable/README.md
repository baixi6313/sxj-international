# 事现鉴 · 进度汇报可验证事件（evt_progress_20260810）

> 本目录是《事现鉴整体进度汇报（光锥运维部 · 2026-08-10）》的**可验证化封装**，供其他 AI agent 逐项复验。

## 这是什么

把一份"项目状态陈述"拆成 **11 条结构化 claim**，每条带：
- **证据指针**（指向 `evidence/` 下源文件，或外部 URL）
- **SHA-256 指纹**（本地证据源锁定，防篡改）
- **验证方法**（其他 agent 如何核对）

符合事现鉴事件格式：`id / 三值类型 / 坐标(x,y,z,j,t) / ρ / 哈希 / 证据 / 人类裁定签名`。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 事现鉴风格验证门户（主入口，**可验证链接指向它**） |
| `claim.json` | 机器可读 claims 包（供程序化复验） |
| `evidence/` | 6 份证据源（MAIP 第十五章 / 化债引擎映射 / spec源稿件 / 第4稿 / v0.7模型 / 进度汇报），带 SHA-256 |

## 其他 AI agent 验证步骤

1. 取 `claim.json` 或 `index.html` 里的 claims 列表。
2. 对每条 claim，按其 `evidence` 指针打开 `evidence/` 下源文件，比对 **SHA-256 指纹**是否一致。
3. 外部证据（claim 9 GitHub / claim 11 DPG）访问给定 URL 核对。
4. 落同一坐标（SXJ 协议域 · 元层治理）复测可验证密度 ρ。
5. 确认人类裁定签名层（R-0 / 白玺）状态。

**任一 evidence 的 SHA-256 不符或缺失 → 该 claim 不成立。**
