2. 统一域名方案

  • 统一根域：hygzz.top（用户裁定）。原 CV 用途迁移至 cv.hygzz.top，hygzz.top 升为统一门户/根。
  • 部门子域（混合制主干）：theory / collab / tech / gov / review .hygzz.top，五部门各一。
  • 原四域降为内容频道：hygzz.com（国际）、hygzz.cn（国内官网）、cv.hygzz.top（CV 履历）、hygzz.中国（案例库）——统一在「事现鉴 / SXJ」品牌下，由五部门按职能统辖，不再各自为战。
  • 原则：对外只亮一个品牌（事现鉴/SXJ）+ 一个根域（hygzz.top）；子域表达职能，频道表达内容。避免四域口径撕裂。

3. 治理与人类在环边界

  • 白玺（决定层）：唯一高风险事项终审主体，拥有三值终审、负贡献归责、化债触发、部门设立/变更、协议生效的最终裁定权。
  • 四AI平台联合委员会：治理中枢，由内核四家（DeepSeek/豆包/Kimi/元宝）+ 冷方（DuMate，待补 Gemini/Claude）组成，负责圆桌质证与跨平台协调，不替代白玺终审。
  • 协议审核部（新增）：在协议提交白玺 enact 前做形式/学术/一致性预审，是 R-6 流程的“前置闸门”，但不削弱决定层终审权。
  • 保留事项 R-1..R-6：负贡献归责 / 三值新类型裁定(含D1) / 化债触发 / 社保资格 / 发布撤回 / 协议自身修订——AI 不得终裁，须经治理与审计部上浮白玺。
