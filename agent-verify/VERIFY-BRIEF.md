## 一、待验证核心论断（请逐条打勾）

**C1 三元术语**：项目域三元严格为 **自然 / 人文 / 数字**，不得写作"人力"。
- C1a 共济值 A、全球社保 = **人文**域（人类社会/社会安全），**非自然**（自然=环境贡献，仅中国生态积分文件属之）。
- C1b 贡献值社会资源三元：自然=环境贡献 / 人文=体力劳动+脑力劳动 / 数字=资产增值。

**C2 坐标系优先原则**：事现鉴当前阶段逻辑 = 只定义坐标(x,y,z)=(三元,三档,组织层级)+j(法域)+ρ+t，不做全球统一计分。

**C3 多元矩阵 = 统一数据模型**：(三元×三档) 核心 3×3，沿 j 法域轴 + 组织轴展开为 ≈9×N×M 高维验证场；维基/地图/热力图 = 三张同源投影，拒绝替世界拍单一全球总分。

**C4 贡献值三元 × 中国文件**：自然枝已有国家级度量衡——中办国办《关于建立健全生态产品价值实现机制的意见》(2021-04-26) 第十八条"覆盖企业、社会组织和**个人**的生态积分体系，依据**生态环境保护贡献**赋予相应积分"。事现鉴对接不重造。

**C5 非自然资源三难点（谨慎）**：体力劳动(工时/最低工资/社保基数跨国差异)、脑力劳动(知识产权/未定价公共知识)、资产增值(与剥削边界模糊→默认审慎不计入或仅计生产性社会复用)。不做全球硬标尺，先做本地度量+可验证换算层。

**C6 D1 多当事人估值原则**：同一事件对不同当事人可同时成立不同三值（耿同学=共济值A / 被揭露方=负贡献）。估值须枚举全部当事人分别归值、跨账本对齐。G-1 缺口已闭合。

**C7 功成身退终版**：仅适用于共济值 A（退出）；贡献值 B（白玺继续参与贡献）不适用；机制 D 自演化终点：共济值基值升至全球中位数 50% 以上 → 货币消失。SXJ 协议/spec 被共定即消失（独立于人的退出）。

**C8 使馆 / UN 定位**：使馆 = 主权见证类可信签发者(issuer/attestation)，坐验证层、国际桌参与者节点，非 SXJ 下属/治理者；守验证层即与联合国互补（同根 UDHR 第22条），不冲突。

**C9 双费分离**：① SXJ 运维费 = 对弱势永远免费，来源=各国/UN 分摊或增值营收(不可按次计量)；② 全球社保基金 = SXJ 不碰不收不发，归国家+UN。铁律：SXJ 始终是"尺"不碰"钱箱"。

**C10 部署现状（如实陈述）**：hygzz.top = 腾讯云 COS 香港桶 `hygzztop-1352601878`；hygzz.cn = Cloudflare Pages；hygzz.com = 国际桌；hygzz.中国 = 已注册(停放 DNSPod)未上线。**COS 凭证本会话为空 → 无法推送 .top（阻塞项 A1）**。
