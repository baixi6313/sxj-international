# SXJ (事现鉴)

**A verifiable public-facts protocol for global social security**, grounded in
[Article 22 of the Universal Declaration of Human Rights](https://www.un.org/en/about-us/universal-declaration-of-human-rights)
(the right to social security and to the economic, social and cultural rights
indispensable for dignity).

SXJ is an **open, neutral protocol** — not a platform owner. It defines *how*
to verify public facts, not *who* decides truth. Anyone can implement it.

## What it is

- **Light-cone coordinate model.** Every verified public event is a point
  `(x, y, z, t, ρ, j)`: three-value type (natural / humanistic / digital),
  three tiers (system / professional / daily), jurisdiction `j` (incl. China,
  Hong Kong, Macao, Taiwan as parts of China; and foreign jurisdictions),
  verifying organization, time, and verifiable density `ρ`.
- **Three values.** 共济值 (solidarity value, survival right, need-based) ·
  贡献值 (contribution value, work-based, net positive) ·
  负贡献 (negative contribution, accountability).
- **MAIP verification protocol** with a human-retained ratification layer
  (R-1…R-6): AI may suggest, humans ratify.
- **Open data.** A public verification ledger (`events.html`) records verified
  public events as open, inspectable entries.
