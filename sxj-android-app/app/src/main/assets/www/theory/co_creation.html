一、定位与终极目标
终极目标 = 全球社保（UDHR 第 22 条）。事现鉴 / 共创论不取代各国社保，而是提供一把公共验算尺——统一度量衡工具，让任何公共事实都可被独立验证、持久化、并接回现实后果回路。
SXJ = 基于《世界人权宣言》第 22 条的可验证公共事实协议。它把"你已经在做的事"（交叉验证、公共记录）收成一把可携带、可互认、可追踪的尺。
2026-07-29 洞见：事现鉴不是未来要新建的复杂系统。南京博物院文物事件、耿同学学术打假、小红书前员工期权——这三件已自发形成"集体需求（共济值）的事现鉴"。理论贡献在于统一度量衡 + 持久化 + 现实后果回路，而非发明验证本身。

六、三值体系
共创论以三值刻画人与公共事实的关系：
值本质锚定

贡献值 CV按劳 · 净值 = 正减负拿钱能解决之事（市场可结算 · 个体 · 物质）

负贡献归责四条件（须同时满足）

  • 主体性 —— 行为出于可归责的主体
  • 因果性 —— 与损害之间存在可验证因果链
  • 可避免性 —— 在当时的条件下本可避免
  • 修复性 —— 存在可执行的修复路径

七、权重 A+B 并存
权重计算原则已定（2026-07-30）：A + B 两模式并存，以"金钱可解性"为边界：
  • A = 军功台阶 —— 离散固定增量 · 即时可累积 · 链 10 友好 · 作为基线（对应共济值 / 集体 / 非物）
  • B = 股份制比例 —— 扇区 · 公信力修正（对应贡献值 / 个体 / 物质）
校准参数：全球城市化率 > 50% → 物质边际效益极小 → 共济值成主导轴。同类"发展饱和"参数（极端贫困率 / 恩格尔系数等）可参照。具体数值公式仍挂起，须先立"宪法性行动约束规则"（规则之规则）再细化。
共识判定由人头票（社区热点）驱动，B 不替票。
共助外语锚词 = 德语 Schicksalsgemeinschaft（命运共同体，原指海难同船幸存者，与"同舟共济"船喻同源）。共助 / 同舟共济的一致性命名留公开讨论，暂无定论。
八、共济值终极定义（2026-07-30 用户定调）
共济值 = 初始社会保障财富 = 世界人权宣言（UDHR 第 22 / 25 条）的实现。
财务自由 = 共济值，定义为"社保 / 共济值覆盖日常支出"（非个人财富态）。
用户以自身过渡态举例（未就业期间仍由社保维系）说明：当前为部分代际 / 家庭依赖的过渡态；终极 = 全球社保覆盖日常支出，连家庭转移依赖也消解。
操作指标"全球社保能否覆盖日常支出"比抽象"共济值 ≥ 50%"更准（后者降为系统态相关量 / 治理消失条件）。
理论锚：三值中"共济值 = 按需 · 生存权" → 社保覆盖 = 按需实现，与前提"共济值 = 钱解决不了"自洽——此处财务自由是"共系统覆盖我"而非"我很有钱"（属 A 非 B）。
注意：财务自由 = 共济值的生存 / 物质层终极；共济值仍含非物公共品（真相 / 确权 / 互助 / 共识），勿整体压缩为"钱"。
九、贡献值定义（2026-07-30 用户定调）
贡献值 = 个人奋斗 + 化债 + 兴趣买单等社会经济综合体（生存地板之上，个人与经济社会相交）。
当共济值确保人不必为生计奔波 → 人可为兴趣买单 / 行动，此即贡献值。即：
  • 共济值 = 财务自由（自由 FROM 生存）
  • 贡献值 = 为兴趣贡献（自由 TO 行动）
对应三值"共济值 = 按需 · 生存权" → "贡献值 = 按劳 · 净值"，是"按需 → 按劳"的实现与负 → 正自由进阶。

A 是地板，B 在其上生长

A = 必需 · 集体（生存权底线）；B 在地板之上生长 = 涌现 · 兴趣驱动。
无共通则 B 被扭曲为生存苦役；有共通则 B 成纯兴趣贡献。
"化债" = 将自身负债清转为净（接三值 净值 = 正减负）。贡献值仍 = 按劳 · 净值 = 正减负，负贡献 / 归责（伪造等）仍扣减。
"为兴趣买单"须解为"为兴趣投入行动 / 资源"，非被动消费——避"躺平 / 消费主义"误读。
十、四阶助法（共创论社会学）
从个体到国际的四阶递进：
  • 自助（个人）
  • 互助（组织）
  • 公助（社会 · 以国家为固定主体）
  • 共助（国际 · 跨国联动 / 跨边界互助，同舟共济）
共助 ≠ 公助：公助以国家为固定主体；共助是国际间联动。此四词与日本社会政策既成"自助・互助・共助・公助"框架完全同构（共助 = kyōjo = mutual aid / social solidarity care）。用户独立重构，强证术语具原理性。

十二、命名演变：共通值 → 共济值（2026-07-30）
A 值由「共通值」更名为「共济值」。原因：
  • ① 原型「环宇光锥舟」= 同舟共济；
  • ② 中（同舟共济）/ 日（同舟共済）/ 德（Schicksalsgemeinschaft · 海难同船幸存者）三语在"同船互济"上同源统一，锚词更稳。
共助（第四阶 · 国际联动）不变；共济值（生存权 · A）≠ 共助（国际联动 · 第四阶），二者层级不同，勿混淆。
