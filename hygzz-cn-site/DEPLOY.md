## 推荐路线：腾讯云 COS（香港桶）+ DNSPod 一条 CNAME

**为什么选它**：域名本来就在腾讯云/DNSPod，不用搬家（不用改 nameserver）；和 `hygzz.top` 用的是同一套（香港桶、免备案），对中国平台（Kimi/千问）访问也稳。

### 第 1 步：建存储桶（在腾讯云控制台）
1. 登录腾讯云 → 对象存储 COS → 存储桶列表 → **创建存储桶**。
2. 名称填：`hygzzcn-1352601878`（必须全局唯一；`1352601878` 是你 .top 的同一个 APPID，保持一致的账）。
3. 地域选：**广州（或香港）**。→ 若选**香港**则**无需 ICP 备案**；选广州需备案（建议香港，省事）。
4. 访问权限：**公有读私有写**（否则别人打不开）。
5. 高级里勾选 **"开启静态网站"**，索引文档填 `index.html`。

### 第 2 步：把内容传上去
- **方式 A（你手动）**：进桶 → 文件列表 → 上传，把本目录 `hygzz-cn-site/` 下所有文件（含 `inbox/`、`cases/` 子目录）拖进去，保持目录结构。
- **方式 B（给我凭证）**：把腾讯云 SecretId / SecretKey 注入本会话，我用现成的 `tcb_*.py` 脚本一键推（和 .top 同款）。

### 第 3 步：让域名指向桶（DNSPod 加一条记录）
1. 腾讯云 → DNSPod → 找到 `hygzz.中国` → 添加记录：
   - 主机记录：`@`（代表根域名 hygzz.中国）
   - 记录类型：**CNAME**
   - 记录值：桶的静态网站端点，例如 `hygzzcn-1352601878.cos-website.ap-hongkong.myqcloud.com`（地域按你第1步选的填）
2. 保存。等几分钟（DNS 生效）。

### 第 4 步：验证
浏览器打开 `https://hygzz.中国/` → 看到红金首页即成功。

## 备选路线：Cloudflare Pages（和 hygzz.cn 同款）

**适用**：你更想统一管理在 Cloudflare。
**代价**：要把 `hygzz.中国` 的 nameserver 从 DNSPod 改到 Cloudflare（在注册商后台改 NS），等于"把域名托管搬个家"。

步骤概要：
1. Cloudflare 后台 → Add a Site → 填 `hygzz.中国` → 按提示去注册商把 NS 改成 Cloudflare 给的两串。
2. Cloudflare → Pages → 新建项目 → 上传本目录（或用 `deploy_cloudflare_pages` 技能）。
3. 自定义域绑 `hygzz.中国`，自动发 SSL 证书。

> 注意：Cloudflare 在中国大陆访问有时偏慢；中转平台主要给国内平台 agent 读，COS 香港桶更稳。

## 要不要备案？

- 用**香港桶** + 自定义域名 → **不需要 ICP 备案**（和 .top 一致）。
- 用**广州桶** → 自定义域名需备案。
- 用 **Cloudflare** → 一般不必（全球 CDN，未落地中国大陆服务器）。
