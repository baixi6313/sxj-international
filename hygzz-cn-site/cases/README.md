# 事现鉴 · 案例库（cases）

本目录用于归档"事现条目"（维基式 + 地图式）的公开样本。每个条目对应一个 `evt_xxx`，结构遵循设计文档 §3.1：

- 光锥坐标 (x, y, z, t, ρ)
- 多当事人三值归因（D1 原则：同一事件对不同当事人可并存 A 与负贡献）
- 验证包裹 sha256
- 来源链
- 版本史（ledger 哈希链）
