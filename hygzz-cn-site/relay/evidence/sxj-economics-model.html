① D 机制演化：共济值基值 → 货币消失阈值

D 机制自演化终点：共济值基值（生存层底）逐步升至「全球中位数 50% 以上」；跨过该阈值 → 货币消失（生存层普遍覆盖，为生存之交换不再必要，贡献值转为自由行动层）。本模型用逻辑斯蒂增长刻画基值趋近阈值的过程。

纵轴 = 共济值基值占「全球中位数生存成本」的百分比（指数 100 = 中位数）。红线 = 50% 阈值（货币消失触发线）。
当前基值（第 0 年）：8% 阈值：50% 预计跨越年份：— 货币未消失
模型假设：基值初值 8%，饱和上限 60%（故可越过 50%）；年增速 r = 0.20 × α × (0.5 + 0.5ρ̄)。数值为示意，用于呈现「采纳越快、跨越越早」的动态，非预测。

② 三值流量：共济值 A / 贡献值 B / 负贡献

A = 按需·生存权·非物（蓝）；B = 按劳·净值=正−负·物质（金）；负贡献 = 追责（珊瑚）。先天残衰病 ≠ 负贡献；归责须主体性+因果性+可避免性+修复性。

A / B 的分界线即「环境三元·被动承担 ／ 本人·主动抉择」：不由本人选择、不可避免的部分（环境三元·被动承担）→ 归 共济值 A 社会共担，且不构成负贡献（不满足归责四要件）；由本人选择、可避免、有主体性的部分（主动抉择）→ 归 贡献值 B 的净值，正负皆由本人承受。注意：自然 / 人文 / 数字「三元」既是本人主动行动的媒介，也是被动承载其上之环境——详见 ⑤。

③ 热密度：治理指标（与"中位数/超平均"理论层分离）

关键分层：热密度是治理层面的操作指标——治理拿它判断"这件事此刻有多热、验证多密"，是"用"的；中位数 / 超平均是理论讨论层面的概念锚点——讨论系统应为谁设计、是否代表中位数的人，是"想"的。二者层级不同，不可焊进同一公式。

B. 中位数 / 超平均（理论讨论层）

这是概念性讨论：系统是否服务于中位数的人？超平均者是否被代表？它是 D 机制"全球中位数 50% 以上"阈值的理论锚点——一种关于"什么是普遍 / 公平"的主张，不由热密度计算得出。

分层小结：热密度管"此刻如何治理"（操作指标，治理据此升级复核），中位数 / 超平均管"系统应当为谁设计"（理论锚点）。D 机制以"全球中位数 50% 以上"为货币消失阈值，是理论主张；热密度只反映当下验证网络的活跃度。前者是"想"，后者是"用"，不可混淆。

④ 债务 → 贡献 双轨转换（v0.7 · 核心闭环版）

★ v0.7 核心（白玺 2026-08-10 08:13 裁定）：化债真正内核＝负贡献核算（珊瑚·归责四要件）∥ 生成新贡献（金·B）并行 → 置换现有债务 → 贡献净值 N(t)。货币消失(D机制 c→1)是置换完成的终态结果而非手段。在事现鉴坐标场内，用田忌赛马把盈余格余量匹配缺口格、财政直销注入基石(共济值 A 基值)、热度密度闸控节奏；选一个场景看双轨如何并行运作。

⑤ 净值 ↔ 动态均衡：其关系在于「本人·主动抉择」＋「环境三元·被动承担」

净值不是一个静态数字，动态均衡也不是泛泛的收益减损失。二者的接口是同一件事里两种性质不同的分量，且构成耦合系统：当事人本人的主动抉择（有主体性、可避免、可归责），与其所嵌入的环境三元（自然 / 人文 / 数字）的被动承担（无主体性、不可避免、非其过）。「本人 + 环境三元」才是完整的分析单位——净值从来不是纯个人事实。

裁定要点（白玺 2026-08-10 修正）

本人 · 主动抉择 → 计入贡献值 B 的净值

  • 本人选择投入的时间、精力、意志、资源
  • 满足归责四要件：主体性 + 因果性 + 可避免性 + 修复性
  • 收益归己（正贡献），代价亦自担；若造成可归责损害 → 负贡献
  • 是「生存之上为兴趣」的行动空间

环境三元 · 被动承担 → 转入共济值 A，不作负贡献

  • 自然枝：先天残衰、灾害、生态约束
  • 人文枝：社会结构、他人过错、体制 / 周期波动
  • 数字枝：系统规则、数据偏差、技术依赖
  • 三者皆不满足归责四要件 → 不得记为负贡献；由社会共担（A 覆盖）

一句话：净值只对本人主动抉择负责；环境三元的被动承担由共济承接。动态均衡 = 这条界线在时间轴上的移动过程——共济覆盖率越高，压在个人净值上的环境被动分量越少，净值越纯粹地反映其自由选择。
关键耦合：同一「三元」既是本人主动行动所借的媒介（贡献值 B 经此产生，见 ② 社会资源三元），也是被动承载于其上的环境——将二者拆开看，才是完整的「本人 + 环境三元」。

金色 = 本人主动抉择净收益（η·g·t − L₀ − l·t）；珊瑚红 = 环境（三元）被动承担累计 P(t)；蓝色阴影 = 共济吸收 c·P(t)；白线 = 个人实际净值 N(t) = 主动净收益 − (1−c)·P(t)；绿虚线 = 平衡点；蓝竖线 = 决策时点 T。珊瑚红之下分解为自然 / 人文 / 数字三元，见下方「环境构成」。

自然枝 = 生态 / 灾害 / 先天；人文枝 = 社会结构 / 他人 / 体制；数字枝 = 系统规则 / 数据偏差。三者皆属「不由本人选择」的环境，应归共济值 A（且不构成负贡献）。
公式：N(t) = [η·g·t − L₀ − l·t] − (1−c)·P(t)。方括号内是主动抉择分量（归 B）；(1−c)·P(t) 是尚未被共济吸收、仍压在当事人身上的被动承担残量（应归 A 却尚未覆盖的部分）。
• 动态在哪里：拉高 c（共济覆盖率）→ 白线抬升、平衡点提前——同一个人、同样的努力，仅因社会承接了被动分量，净值就转正。这说明「个人净值」从来不是纯个人事实。
• 与 ① 的联动：c 的现实取值由 D 机制基值决定。基值 8% → c 极低；基值跨过中位数 50% → c → 1，被动承担几乎完全社会化，此时净值 = 纯粹主动抉择的记录，贡献值 B 正式成为自由行动层。
• v0.7 衔接：④ 卡的「置换 → 净值」即本公式的化债操作化——`η·g·t` 对应新贡献生成(金轨)、`L₀+l·t` 对应负贡献核算(珊瑚轨)、`(1−c)·P(t)` 对应尚待共济承接的被动残量。两卡共用同一净值式，④ 是化债场景特化，⑤ 是通用净值模型。
• 三轴仍在其中：主动与被动两侧各自可分解为物质 / 时间 / 意志·兴趣三轴，非货币量（花的时间、耗的心力）同样计入，只是归属不同侧。
• 尺度放大：个人层的被动承担是疾病与失业；国家层是外部冲击与历史负债；国际层是气候与体系性风险。层级越高，P(t) 越是结构性的，越需要更长时域与更高 η 才能穿越。
• 本人 + 环境三元（2026-08-10 修正）：被动承担并非笼统的"社会"，而是事现鉴 canon 的「社会资源三元」——自然 / 人文 / 数字。这同一三元既是本人主动行动所借的媒介（贡献值 B 经此产生），也是被动承载于其上的环境；将二者拆开看，才完整。下方「环境构成」按当前尺度给出三元各自的未承接残量。
