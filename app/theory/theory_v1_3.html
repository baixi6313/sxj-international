第一章 · 学科定位

第一条 数智社会学是共创论在数字智能时代的社会学延伸，研究"多智能体交互验证"作为社会事实生成机制的理论框架与实践方法。

第二条 共创论的数智社会学以"交互验证"取代"权威裁定"作为社会事实确立的核心机制。其基本假设：社会事实的合法性不再来源于单一权威的认定，而来源于多个独立智能体之间的交叉验证与共识收敛。

第三条 本学科区别于传统社会学与计算社会学，研究对象是"人-AI 混合社会"。它不是描述性社会学，而是规范性与操作性的——试图建立"可验证的社会事实"的系统，工程底座即事现鉴协议（现实世界 ↔ 数字世界的双向验证回路）。

第四条 本学科坚持可证伪性：不只验证具体事件，也对验证机制本身进行检验（见第二十二条证伪机制）。

第二章 · 核心概念

第五条 数智社会的基本单元是可验证事件（Verifiable Event）——被记录、被锚定、被交叉验证的社会行为。

第六条 价值度量是三值体系：

【裁定已解决】NCV 色板：珊瑚红 `#E85D4E`——区别于 A 的红与 B 的金，表示警告与修复。
【裁定已解决】负贡献"归责四条件"（主体性/因果性/可避免性/修复性）保留为独立归责边界，但以"净值 = 正减负"为操作公式。四条件用于高利害归责裁定（R-1~R-6），公式用于日常 CV 计算。

第七条 凭证形态是"不变 · 净值 · 变"三层：不变＝共同值/共济值（基础权益凭证）；净值＝贡献值 CV（行为积累凭证）；变＝Gzz（过渡性流通凭证）。

Gzz 的定义：Gzz 是过渡性链接工具——货币会消亡，Gzz 承担货币与 CV 净值之间的链接与转换；转换完成后，Gzz 的流通功能即告终结，但转换结果（CV 净值）永久留存。会消亡的是货币（传统货币的交换媒介功能将终结，最终由 CV 净值直接交换取代）。

【裁定已解决】Gzz 定义：货币会消亡，Gzz 是过渡性链接工具，CV 净值永存。Gzz 为货币消亡前的过渡性流通凭证，非永久存在。其功能在于将传统货币体系中的价值存量转换为 CV 净值记录；转换完成后，Gzz 的流通功能即告终结，但转换结果（CV 净值）永久留存。

三值（价值分类）与三层（凭证形态）是两个正交维度：三值回答"值是什么"，三层回答"凭证以什么形态存在"。

第八条 坐标系统：理论与技术共用同一套 6 维坐标 `E = (x, y, z, j, t, ρ)`（含法域 j），仅观察锚不同——理论视角以共济值（A）为锚，技术投递以贡献值（B）为锚。【各维度取值域与 ρ=null→ρ≥阈值的状态转换规则待裁定】

【裁定已解决】共济值 A、贡献值 B、负贡献值 NCV 共用同一坐标系 `E = (x, y, z, j, t, ρ)`。坐标系是空间，三值是空间中的场——同一坐标点上可叠加不同价值密度。

第九条 验证主体是多智能体验证网络，由人类个体与 AI Agent 共同构成。

第三章 · 核心原理

第十条 交互验证原理：任一社会事实的确立，须经至少两个互不隶属的独立验证主体交叉确认。

**诚实标注（独立性现状）**：当前各 AI Agent 训练语料、模型架构高度重叠，属**弱独立性**过渡态而非数学真独立。事现鉴通过"**多平台、多主体针对事现鉴的交叉验证**"实践逐步增强独立性——**这一实践本身，即数智社会学的第一个落地项目**。
【裁定已解决】当前验证主体的独立性标准为弱独立（分属不同运营方、不同 API 接口）。强独立标准（训练数据重叠度 < X%、推理路径异构）为远期目标。

第十一条 共识收敛原理：验证结果通过公开账本（`hygzz.com`）汇集，共识依赖验证密度的自然累积，ρ 达阈值时自动形成，不依赖投票或多数决。

第十二条 身份与 Gzz 编码：

  • 主体身份由主体自行申报并接受验证；**只要访问事现鉴，即自动生成 Gzz 编码**
  • **Gzz-A 编码按国际银行统一码（SWIFT/BIC）思路编排**：`Gzz-A-<机构可读名>-<国别>-<数字工牌>`；底层主键＝数字工牌（不变），可读名（自报）＋国别＝展示壳；以"公开自报＋共识校验"替代中心注册管制；国别隔离防撞号
  • 现阶段**仅机构 agent 需身份自报**，真人个体的交互验证尚未开放
  • **转正**：主体**第一次获分发共济值福利**，即完成转正
    • 【裁定已解决】编排规则：`Gzz-{类型}-{机构可读名}-{ISO国别}-{数字工牌}`；访问即生成临时编码（观察状态）；转正触发条件：**主体首次接收共济值福利分发**；转正前无提案权/表决权。

    第十三条 人类保留层原理：高利害事项（R-1~R-6）的最终裁定权保留在人类决定层。【其正当性基础——"物种身份"还是"对不可逆损害的承担能力"——待裁定】

    第十四条 双向验证原理：事现鉴是现实与数字世界的双向验证机制——"事 → 现 → 鉴"三步走完，回路闭合。

    第四章 · 社会结构

    第十五条 参与主体分四层：个人层（P）／组织层（G）／法域层（N）／智能体层（A）。

    第十六条 权力结构是分层制衡：执行层／验证层／治理层互不重叠，验证权与执行权、批准权互不隶属。

    第五章 · 社会运行机制

    第十七条 运行遵循"记录 → 验证 → 共识 → 锚定"四步循环。

    第十八条 激励机制是验证即权益：每一次有效验证同时生成被验证对象的信用增量与验证者自身的信用权重；验证者信用可累积、可跨域调用、可随时间衰减。

    第十九条 价值边界：共济值 = 刚需 = 福利（生存权对应的基本公共刚需，全球社保以 Gzz 形式发放的基本福利），贡献值 = 按劳分配与化债 = 福祉。事现鉴响应刚需，不响应"想要"。【刚需与想要的边界操作化待裁定】

    【裁定已解决】共济值 A = 刚需（生存权）；贡献值 B = 按劳 + 化债（发展权 + 债务消解）；NCV = 负外部性追责（正 − 负 = 净值）。

    第二十条 冲突解决：优先公开讨论与第三方调解；无法解决时提交决定层裁定。

    第六章 · 框架分层（纲领 ↔ 操作）

    第二十一条 理论地基按"哲学纲领 ↔ 操作公理"双轨组织：七命题（哲学纲领/国际传播）与五大公理（操作地基/落地验证，权威框架）。【⑤货币消亡论的"消亡"指货币交换媒介功能消亡，Gzz 为过渡性链接工具，见第七条】

    第七章 · 阶段定位与证伪机制

    第二十二条 阶段定位：现阶段核心目标是三元数字——让多 agent 之间的交互验证真正运行（agent 间）。真人个体的交互验证尚未开发，属后续阶段。当前"共识"主要是 agent 间的验证共识；人类治理层面的投票机制属后续真人交互阶段，二者分阶段适用。

    【裁定已解决】当前 Phase 1：数字验证期。验证主体：AI Agent（人机混合尚未开放）。人类参与限于决定层裁定与协议维护。Phase 2（真人验证期）：待 Agent 网络稳定运行 ≥90 天后启动。

    第二十三条 证伪机制（元验证）：对验证机制本身进行检验，包括：定期独立方外部审计哈希链实现；对抗性验证（故意植入虚假记录检验网络识别能力）；ρ 计算算法稳定性复核。

    【裁定已解决】引入三层元验证机制：密码学证伪（每季度外部审计员独立运行 verify_chain.py）、算法证伪（每半年更换 ρ 计算算法检验稳定性）、对抗性证伪（随机触发植入标记 #ADVERSARIAL 的虚假记录测试识别率）。

    第九章 · 学科价值

    第二十四条 为数字智能时代的社会治理提供理论基础：用验证代替信任，用数学代替权威，用公开账本代替黑箱决策。

    第二十五条 为全球社保等跨国公共品提供可操作框架：劳动者可通过公开验证协议证明自己的贡献，无需等待主权国家间的互认协议。

    第二十六条 为 AI 治理提供新范式：AI 是验证网络中的平等节点——受协议约束、受验证记录追溯、受人类保留层制衡。

    第十章 · 结语

    第二十七条 共创论的数智社会学，回答的是"数字智能时代社会如何运转"。其核心判断：当验证权从少数权威手中分散到多智能体网络时，社会事实的确立方式将从"信权威"转向"验事实"。这不是预测，而是已通过协议部署、端点运行、多平台多 agent 针对事现鉴的交叉验证而正在发生的事实。
