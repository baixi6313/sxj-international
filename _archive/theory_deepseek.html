前言

共创论不是一套哲学宣言，而是一套可操作的社会协议。它的核心工具是"事现鉴"——一个让任何行为都能被公开记录、验证、调用的公共协议层。

我们的起点不是"如何拯救世界"，而是"如何让人不再被欺骗、被屏蔽、被定义"。

一、元问题：为什么有人知道，有人不知道？

1.1 沙滩隐喻

一个小孩和一个历经风浪的人，在同一片沙滩上晒太阳。

  • 小孩问："你努力了那么久，最终不也和我一样在这里晒太阳吗？"
  • 但你指出："需要去看看，才知道自己不知道。"

在事现鉴里，这个问题的答案是：

"让所有人都看到——不是'你可以看到'，而是'大家都看到'。"

可见性不是一种特权，不是一种奖励，而是事现鉴协议的默认属性。

1.2 认知差异的根源

认知差异不是智力或努力的差异，而是"可调用的验证记录集"的广度差异。

旧系统通过三重独占维持着这个差异：

  • 知识独占（知网等学术数据库）：锁住论文、研究成果、引用数据
  • 技术独占（国家专利库、企业/个人专利）：锁住技术方案、使用方法
  • 经验独占（抖音、快手、视频号等平台）：锁住行为记录、经验分享

这三重独占共同维持着一个循环：认知差异 → 资源分配差异 → 命运差异。

二、共创论的核心公理

公理一：人无差别，行为有迹

在去除一切外部资源标签（学历、资产、身份）后，人与人之间没有本质差异。差异只来源于行为的验证记录。

  • 任何人在事现鉴中以"验证账户"状态启动，初始权重相同
  • 账户的差异只来源于行为验证记录的数量和质量
  • 行为记录是公开、可溯、可复核的
  • 学历、职称、资产不作为系统内的权重依据

公理二：使用优先于所有

资源不归谁所有，只被谁使用。使用轨迹公开记录，作为下一轮调用的依据。

  • "所有"这个动词在事现鉴中被删除
  • 资源处于"正在被使用"或"空闲可用"两种状态
  • 下一轮使用权不依赖身份或资本，而依赖过去使用同类资源时留下的验证记录密度

公理三：验证即权益

每一次验证行为，都在同时生成两种资产：

  1. 被验证对象的信用增量
  2. 验证者自身的信用权重
  • 验证不是"劳动"，而是"信用挖掘"
  • 验证者信用可累积、可跨域调用、可随时间衰减

公理四：共同值 = 被验证过的公共需求的加权总和

共同值不是预设的道德理想，而是由大量独立验证记录汇聚后，系统自动识别出的"当前可被确认的群体性刚需集合"。

  • 它不是预设的，而是由验证记录自行汇聚
  • 它是动态更新的
  • 它是可操作的——直接链接到闲置资源的匹配和调用

公理五：刚需（Need）≠ 想要（Want）

事现鉴只响应"刚需"（Need），不响应"想要"（Want）。

  • 刚需分为两层：个人刚需（食物、水、住所、基础医疗）与团体刚需（公共安全、交通秩序、垃圾处理、信息沟通）
  • 两层高度重合——团体刚需未满足时，个人刚需必然受损
  • 刚需的清单是有限的、明确的、可客观验证的

三、事现鉴的核心机制

3.1 最小可运行单元

事现鉴的每一次有效操作，由三个环节构成：

环节内容状态
① 个人上传任何人可上传自己的行为轨迹原始数据进入系统
② 他人认证至少两位独立验证者确认其真实性验证发生
③ 阈值共识验证记录积累达到阈值后，自动标记为"已验证事实"成为公共知识

这三个环节缺一不可：

  • 只有"个人上传"而没有"他人认证"= 孤证（无效）
  • 只有"他人认证"而没有"个人上传"= 无源之水（无效）
  • 只有前两者，没有"达到阈值"= 待验证（暂存）

事现鉴不依赖任何机构、权力或平台——它只需要至少两个愿意验证的人，和一个愿意上传的人。

3.2 贡献值（CV）计算

任何行动都同时产生正贡献和负贡献，其净值决定它在系统中的价值：

变量定义来源
正贡献（+）该行动对被验证对象产生的可观测正向影响由至少2位独立验证者确认并量化
负贡献（-）该行动对他人/公共资源造成的外部性损害由受损方或第三方验证者提出
净值（Net CV）正贡献 - 负贡献系统自动计算

3.3 GZZ代币机制

GZZ是事现鉴系统中的价值计量凭证，记录"行动净值的累积结果"。

步骤操作说明
①系统记录一个行动的净值为N例如：+4、-2、+3
②净值为正时，系统向行动者发放N个GZZ例如：+4 → 获得4 GZZ
③净值为负时，行动者需要支付N个GZZ（或通过后续正贡献抵消）例如：-2 → 需支付2 GZZ
④每个账户的GZZ余额 = 所有行动净值的累计总和反映该账户在社会系统中的整体贡献状态

GZZ不是"奖励"，而是"计量凭证"。

3.4 GZZ与债务化解

GZZ提供了一种不依赖外部货币的债务化解路径：

维度旧系统（美元负债模式）事现鉴（GZZ机制）
债务来源必须借入美元才能参与全球贸易债务来源于正负贡献净值差额
债务度量美元（由美联储发行）GZZ（由验证记录自然生成）
债务清偿必须用美元偿还可以用"激活闲置资源"来对冲
债务累积利息导致债务越滚越大净值由验证记录决定，验证过期后权重衰减

3.5 代偿的两种形式

形式说明适用场景
货币代偿GZZ按锚定汇率兑换为现金负贡献无法物理消除（如精神压力）
行动代偿GZZ用于激活闲置资源（安居房、隔音设备、接送服务）负贡献可以被物理对冲（如噪音、出行不便）

行动代偿是事现鉴的核心优势：它不依赖货币流通，而依赖资源调度。GZZ支付后，直接激活一个"已验证过的稳定环境"，使受害方获得实质性修复。

四、现实验证场景

4.1 案例：老旧小区修水管 vs 高考

这是事现鉴机制在现实中最完美的测试场景。

贡献类型具体内容验证者
正贡献水管更换提升生活质量小区居民、物业、社区工作人员
负贡献（短期）施工噪音影响高考生复习与休息高考生本人、家长、邻居
负贡献（延伸）施工影响出行小区所有居民

净值计算示例：

  • 正贡献总量：+100（长期，对200户居民）
  • 负贡献（噪音）：-50（短期，影响10位高考生）
  • 负贡献（出行）：-20（影响50户居民）
  • 净值（初步）：+30

代偿方式（行动代偿）：

  • 施工方支付GZZ → 调度闲置安居房为高考生家庭提供临时住所
  • 施工方支付GZZ → 调度企业闲置隔音设备为受影响家庭降噪
  • 负贡献被对冲后，高考生家庭确认："噪音已不影响复习"

债务化解：

  • 施工方的"道德债"通过GZZ支付化解
  • 高考生家庭的"学习债"通过获取稳定环境化解
  • 闲置资源提供方获得GZZ作为贡献凭证

4.2 这个案例证明的四个核心命题

命题内容
①任何一个行动都可以拆解为正贡献与负贡献，其净值才是真实价值
②负贡献可以通过"激活闲置资源"来对冲，而不需要现金补偿
③市政安居房、企业闲置产品、个人闲置物品——都可以通过验证记录进入"公共可用池"
④GZZ是这个对冲过程的计量凭证——它记录"负贡献被抵消"这件事本身

五、对抗算法茧房

5.1 问题：旧系统的"伪启蒙"

抖音让全球普通人分享经验，打破了地域和阶层的信息壁垒——这是初步的"启蒙"。但算法根据你的观看历史不断强化你的偏好，屏蔽你不熟悉的内容——你被困在"信息回音壁"里。

5.2 事现鉴的回应

事现鉴不做内容推荐，不做"热门排行"。它只做一件事："让所有验证记录都以相同权重被检索。"

旧系统（抖音等）事现鉴
内容按"热度"排序内容按"验证密度"排序——一个只有10次播放但被8次验证为有效的方法，排在10万次播放但0次验证的内容前面
算法根据你的历史行为决定你看到什么你可以主动搜索任何关键词，系统返回所有相关验证记录，不区分"你喜不喜欢"，只区分"是否被验证过"
你被动接收信息你主动检索信息
信息被"推荐"给你信息被"提供"给你

5.3 TikTok封禁的证明

TikTok的封禁证明了：当认知觉醒开始突破知识独占与技术独占时，权力独占会发动防御性收缩。事现鉴正是为了应对这种收缩而设计的：

  • 不依赖任何特定平台（数据分布存储、用户自主托管）
  • 不依赖任何特定算法（验证密度排序公开可查）
  • 不依赖任何审批者（验证记录不由单一节点决定）

你无法封禁一个协议，你只能封禁一个平台。

六、数字时代的"敌友框架"

6.1 谁是"敌人"？

不是"某个人"或"某个国家"，而是那些依赖"不可验证的信息不对称"来维持其生存地位的主体：

  • 知识垄断机构（知网等）
  • 技术壁垒持有者（依赖专利封锁的企业）
  • 权力分配节点（依赖行政审批分配的机构）
  • 认知茧房运营商（依赖算法推荐的大型平台）

他们的共同特征是：利益建立在"信息不透明"之上。

6.2 谁是"朋友"？

  • 底层劳动者/经验持有者
  • 求知者/路径追寻者
  • 中小技术开发者/研究者
  • 受困于信息孤岛的个体
  • 愿意共享路径的先行者

6.3 最终定位

"共创论的事现鉴，其'敌人'是依赖信息不透明维持分配的既有结构；其'朋友'是那些因信息不透明而被限制行动空间的人。它不颠覆任何体系，它只是让'公开验证'成为一个可选择的公共层——当这个公共层足够厚实时，'不透明'就不再能作为定价权或分配权的依据。"

七、历史定位：第四次系统置信度切换

人类历史上经历过三次"系统置信度大切换"：

切换事件旧系统失效原因新系统被选择的理由
春秋战国→秦统一诸子百家争论无法终结战争法家提供了"终止物理崩溃"的方案
新文化→新中国封建/民国无法抵御外侮集体动员提供了"最短生存路径"
各国货币→美元体系各国货币无法高效结算全球贸易美元+黄金提供了"通用换算锚"

第四次切换的起点：从"由某种权威主持的全球结算体系"，切换到"由公开验证记录主持的全球协作协议"。

事现鉴正是这个第四次切换的基础设施。

八、最终结论

"让每一个人的价值都可以被验证——不是因为某个人或某个机构'承认'了它，而是因为他的行为轨迹被公开记录，并被其他独立验证者确认为'真实有效'。"

当事现鉴的验证记录足够丰富时：

  • 阶级不再由出身或财富决定，而由验证记录的自然流动决定
  • 命运不再由权力分配，而由路径的可见性决定
  • 价值不再由机构认证，而由公开验证决定

这不是一种新体制，而是一种让"不透明"失效的协议。它不摧毁任何现存系统，它只是在它们的"不透明"之外，建立了一个"公开验证层"。

当这个层足够厚时，不透明就不再能压制价值的呈现。
