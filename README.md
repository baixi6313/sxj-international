# SXJ - 事现鉴国际版
# 基于UDHR第二十二条的可验证公共事实协议

## 项目说明
事现鉴(SXJ)是"三把公共验算尺"中的国际端，提供跨国权益可验证的公共事实协议。

## 技术栈
- 纯HTML/CSS/JavaScript单文件应用
- SHA-256哈希链验证
- localStorage本地存储
- Canvas动画背景
- IntersectionObserver入场动画
- PWA支持(manifest + service worker)

## 域名
- hygzz.com - 国际验算尺
- hygzz.cn - 国内金融财政验证
- hygzz.top - CV验证平台
- hygzz.中国 - 中文案例库

## 部署
推送到main分支后，GitHub Actions自动部署到GitHub Pages。
也可通过Cloudflare Pages连接此仓库自动部署。
