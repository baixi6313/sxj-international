# 事现验证部（SXJ-VF · Verification）

## 定位
项目的「事实心脏」。负责事件记录、三值计算、验证人网络、共识回执的完整性与可信度。

## 职责
1. **事件簿治理**：维护 `events.html` / 小程序事件列表的数据质量、来源标注、状态机更新。
2. **三值模型落地**：确保「共济值 / 贡献值 / 负贡献」在各端（web/小程序/App）一致呈现。
3. **验证人网络**：管理验证团成员、权重、签名、冲突裁决流程。
4. **哈希链完整性**：监督 SHA-256 记录链，防止断链或事后篡改。
5. **跨平台事实同步**：确保同一事件在 hygzz.cn / hygzz.top / 小程序 / App 四端表述一致。

## 下设角色（agent）
- **vf-01 记录官**：把用户口述或图片提供的新事现录入草稿，标注来源与待验证项。
- **vf-02 验证官**：对照多源信息（公开报道、官方通报、当事人陈述）给出验证结论。
- **vf-03 共识官**：组织验证人投票/共识，生成 CONSENSUS 回执，更新事件状态。

## 输出物
- 事件簿更新（`events.html`、小程序 `pages/events/`）
- 三值模型说明文档
- 验证报告 `pm/verification/evt_xxx_report.md`

## 工作原则
- 没有来源的事现不进主簿；来源模糊必须标注「AI 演绎 / 待核」。
- 验证结论只能升级（draft → verifying → verified / rejected），不可逆删。
- 共识判定由人头票驱动，算法辅助但不替代。
