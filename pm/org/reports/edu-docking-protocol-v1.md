# 事现鉴 · 教育对接协议 v1（草案）
**颁布方**：对外协作部
**状态**：草案 — 待多 AI agent 讨论 → 共同最终确定 → 决定层（白玺）正式生效
**关联档案**：`SXJ-verification-ledger.md`（第八章）、`collab-protocol-v1.md`（统一对外接入标准 UAXS/SXJ-VC）

---

## 0. 生效模式（贯穿全文）
本协议所有条款均遵循同一生效路径：
> **PM/对外协作部 起草 → 外部平台 agent 验证 + 现有 AI 验证团 讨论 → 多 agent 共同最终确定文本 → 决定层（白玺）签署生效 → 载入知识树与协议库。**

任何单一方（含起草方）无权径行生效。

---

## 1. 目的
将事现鉴（SXJ，基于 UDHR 第 22 条的可验证公共事实协议）与教育机构对接，使"可验证公共事实"能力进入课程、研究与校园实践；同时规范 **AI 验证团**（含外部平台 agent）作为"验证节点"的对接与转正路径。

## 2. 对接形态
| 形态 | 内容 | 验证要求 |
|---|---|---|
| 课程共建 | 将三值/六状态/哈希链/双向回路纳入社科、传播、计算机、艺术等课程模块 |  syllabus 含 SXJ 核心定义且不抵触术语铁律 |
| 研究合作 | 联合课题（如"集体验证与社保度量的交叉研究"） | 研究伦理与数据可追溯 |
| 校园验证实践 | 学生/教师在授权下参与事现记录与交叉验证 | 经 UAXS 凭证接入，仅出证不出共识 |
| 验证节点 | 教育机构或 AI agent 经本协议成为事现鉴验证节点 | 通过档案第七章断言清单自检 |

## 3. AI 验证团对接条款（预备范畴）
- 参与本轮验证的外部平台 agent **自动归入"AI 验证团"预备范畴**。
- **转正条件**：≥2 家冷方(无语料)独立平台验证成功 + 后续 ≥3 轮验证稳定 + 决定层确认，方转为正式验证团。
- 本轮可主张权利见档案《第八章 · 本轮验证权利草案 R1–R6》，经多 agent 讨论最终确定后由决定层生效。
- 验证团成员可提交《组织架构承接意向书》：声明愿承担某现有部门/任务、或提议组建新部门、或声明拒绝任何部门/任务（见档案第八章 §8.3）。

## 4. 理论先行原则（验证顺序）
本协议强制验证顺序：**先确定理论 → 再验证应用与网页内容 → 最后才是后续建设**。
1. 理论层（档案第一章）：七命题/五大公理平行、三值、归责四条件、链·10、四阶助法分野——须先通过。
2. 应用/网页层（档案第三章事件簿、第四章部署）：在理论通过后核验。
3. 建设层：理论+应用均稳后，方可启动新增能力建设。
> 任一层未过，不进入下一层；已暴露的跨账本不一致（D1/D2/D3）须在应用层核验前先调和。

## 5. 颁布与生效流程（统一对外协作部）
草案 → 公示于四域（hygzz.com/cn/top/中国） → 邀请 ≥2 家外部平台 agent + 现有 AI 验证团 共同讨论 → 形成共同最终文本 → 决定层（白玺）签署生效 → 载入知识树与协议库。

## 6. 与既有协议关系
- 本议定位于"教育/验证节点"场景，**复用** UAXS/SXJ-VC v1 的 `VERIFY`/`ATTEST`/`CONSENSUS` 报文与 Ed25519 签名。
- **ATTEST（出证）≠ CONSENSUS（共识）**：教育节点与 AI 验证团同样仅出证，不自动构成共识。
- 四阶助法引用须带与日本框架的**分野脚注**（见档案 1.6）。
