- **关键提醒**：标准源（top）不干净会经同步放大缺陷 → 已建议"同步前先扫源"。

### 2. 安全合规部（SXJ-SC）
- **头号 P0**：12 个脚本明文硬编码同一枚 GitHub PAT（`ghp_8fJT…`），仍在本地磁盘未吊销。
- **核心判断**：因"未经许可不推 GitHub"铁律，凭证尚未外泄（弹药上膛未击发）；**吊销 1 枚 token 即可一次性关闭 12 处暴露面**，成本极低。
- **已落地**：`.gitignore` 加固、密钥扫描闸门 `secret_scan.py`、UAXS 凭证标准、GitHub 推送禁令。

### 3. 事现验证部（SXJ-VF）
- **核心资产盘点**：全项目 7 条独立事现散落 5 套互不同步账本、3 套 ID 命名法、3 套状态词表。
- **最硬结论**：事现鉴**至今 0 次由本平台验证团独立完成验证闭环**（两条高状态事现均为社会已验证后搬运）。
- **P0 阻断**：小程序"添加事现/证据/验证意见"三录入页曾被贪婪正则误清为空容器，新事现通道物理断裂（已在上一轮据 JS 逻辑重建，待用户手动上传验证）。
- **标杆**：彬县 evt_BX_1998_001 主动"已验证→记录中"降级留痕，是全项目最有说服力的可信度资产。

### 4. 理论研发部（SXJ-TH）
- **体系化成果**：28 条一级引用（官方文件/同行评议/工程/新闻）映射至共创论各主张，且**强制"主张—证据—反证"三元组**。
- **两条须立即修的口径（已提请 PM 定调）**：
  1. "治理消失 ≥50%" 与 ILO 宽口径（52.4% 已覆盖一项待遇）正面对撞 → 建议改为 `共济值 = 覆盖率 × 充足度 × 可验证度`（方案 B）。
  2. 四阶助法与日本厚生劳动省框架**语义不同、顺序相反**（日方共助=社会保险、公助=税收兜底）→ 凡引用须加分野脚注，禁标"日本模式"。
- **关键反证已收录**：Moneda PAR（区块链不解决 ethical trust）、威尔士 UBI 混合结论、突尼斯预辟谣失效。

### 5. 对外协作部（SXJ-CO）
- **交付**：`SXJ-XIP/1` 统一交互协议 v1（Ed25519 非对称签名、VERIFY/ATTEST/CONSENSUS 三报文、SHA-256 哈希链锚定、CRL 吊销、六状态机、错误码全集）。
- **与 UAXS 的升级点**：v1 **必须**用 Ed25519 取代 UAXS 示例中的 HMAC 共享密钥（否则平台可伪造 Gzz 签名，违背"平台不可自证"）。
- **状态**：v1 草案，待 GM 汇总 → 用户批准 → 安全合规部会签生效。
